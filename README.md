# AI파트너 (aipartner.com) 자동 로그인 프로그램

이 프로그램은 Chrome 브라우저를 자동으로 실행하여 **AI파트너(aipartner.com)** 에 자동으로 로그인해 주는 파이썬 자동화 스크립트입니다.

## 파일 구성
- `auto_login.py`: 자동 로그인 파이썬 메인 스크립트
- `run_login.bat`: 윈도우에서 더블 클릭 한 번으로 실행할 수 있는 실행 배치 파일
- `requirements.txt`: 필요한 파이썬 라이브러리 목록

## 동작 방식
1. `https://www.aipartner.com/home` 접속 및 로그인 완료
2. 상단 메뉴의 **[매물 관리]** 버튼을 클릭하여 매물 광고 관리 페이지로 이동
3. 취급 매물 목록에서 아파트 단지 행을 클릭하여 매물 목록 표시
4. 매물 리스트 우측 상단 정렬 드롭다운에서 **'오래된 순'**으로 변경 후 목록 재정렬 대기
5. **연속 재광고 반복 루프 (기본 총 7회)**:
   - 매물 리스트에서 위에서부터 `[재광고]` 버튼이 있는 대상을 탐색 (이미 처리한 매물 자동 스킵)
   - `[재광고]` 클릭 ➔ 툴팁 '바로 재광고' 선택 ➔ 팝업 약관 동의 체크 ➔ 브라우저 confirm/alert 자동 승인
   - 결제/신청 페이지: '모바일확인v2 개인정보 처리 위탁 동의' 체크 ➔ 하단 주황색 [결제하기] 클릭 ➔ "로켓전송이 완료되었습니다." Alert 확인(Accept) ➔ 전송 완료 화면 하단의 [목록] 클릭하여 원래 매물 관리 화면(ad_list) 복귀
   - 1건 완료 후 목록 새로고침 및 '오래된 순' 정렬 상태를 보장한 뒤 다음 매물 연속 진행
6. 설정된 횟수(`MAX_RE_AD_COUNT = 7`) 완료 시 완료 메시지를 출력하고 크롬 브라우저를 깔끔하게 자동 종료(`driver.quit()`)

## 실행 방법
### 방법 1: 배치 파일 실행 (가장 편리)
- `run_login.bat` 파일을 더블 클릭하여 바로 실행할 수 있습니다.

### 방법 2: 터미널 / 명령 프롬프트(CMD)에서 실행
```bash
python auto_login.py
```
